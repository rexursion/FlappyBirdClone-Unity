# Flappy Bird Clone - Unity

A simple **Flappy Bird** clone built with **Unity**. The game is inspired by the popular mobile game **Flappy Bird**, where the player controls a bird navigating through pipes. The goal is to avoid hitting the pipes and survive as long as possible.

## Installation

To run the game on your local machine, follow these steps:

### 1. Clone the Repository

Clone this repository to your local machine using Git:

```bash
git clone https://github.com/your-username/FlappyBirdClone-Unity.git
```

### 2. Open the Project in Unity

Open Unity Hub.

Click on Add and select the folder where you cloned the repository.

Open the project in Unity.

### 3. Build the Game

Once the project is open, go to File > Build Settings.

Choose the platform (e.g., Windows, WebGL, etc.) and click Build.

### 4. Play the Game

After building, you can run the game on your platform.
How to Play

    Press the spacebar or left-click to make the bird flap and fly.

    Avoid the pipes as they will cause you to lose the game.

    Try to survive as long as possible and get a high score!
